# LIFE OS

LIFE OS — мобильная личная книга для планов, привычек, дневника и саморазвития.

## Возможности

- планы на день, неделю, месяц, год и жизнь;
- ежедневные привычки и прогресс;
- рукописный дневник с календарной навигацией;
- книги, конспекты и навыки;
- локальное хранение данных в браузере;
- установка на домашний экран как PWA;
- автономная работа после первого открытия.

## Локальный запуск

Откройте папку через любой статический веб-сервер. Например:

```sh
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Установка на iPhone

Откройте сайт в Safari, нажмите «Поделиться», затем «На экран Домой».

Данные сохраняются только на устройстве пользователя через `localStorage`.
